# Sprite-Stick
MicroSD-Driven Mini USB Display Engine built on RP2040 and USB2642

Sprite Stick is an ultra-compact, high-speed custom USB peripheral engineered to dynamically drive a tiny onboard display while serving as a USB mass storage device. Designed as a sleek, self-contained 4-layer PCB, the hardware combines a high-speed USB 2.0 Hub Controller (USB2642), a Waveshare RP2040-Zero micro-controller, a MicroSD card interface, and an integrated SPI display engine.
